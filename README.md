# Device-Free Human Activity Detection via Wi-Fi CSI

DSP mini-project: a signal-processing pipeline (Hampel filtering,
Butterworth low-pass filtering, STFT spectrograms) plus a CNN to
classify Empty Room / Walking / Walking with Arm-waving from Wi-Fi CSI.

Dataset: Wallhack1.8k (https://zenodo.org/records/13950918)

Status: Phase 1 in progress.
